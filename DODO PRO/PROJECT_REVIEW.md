# خطة المراجعة والتفعيل — AutoLand

## المرحلة 1 — تدقيق النسخة الحالية

- تم التحقق من بناء PHP، ونقاط الدخول، وحماية CSRF، وSQLite، ورفع الصور، وTOTP، ورمز البريد.
- تم رصد أن المشروع لا يحتوي مستودع Git بعد، ولا ميزة جلسة دائمة أو استرجاع كلمة مرور؛ عولجت هذه العناصر في مرحلة التطوير التالية.
- بيئة الإنتاج المناسبة للتطبيق الكامل هي cPanel مع PHP 8.1+ وSQLite. Vercel لا يشغّل تطبيق PHP/SQLite هذا كخادم ديناميكي دون إعادة بناء الخلفية وقاعدة البيانات.

## المرحلة 2 — دخول الإدارة واسترجاع الحساب

- زر إظهار/إخفاء كلمة المرور في الدخول وإعادة التعيين.
- «تذكّر هذا الجهاز» لمدة 14 يوماً، برمز عشوائي محفوظ كتجزئة ومربوط بملف مفتاح خاص خارج الويب. يُدوّر الرمز عند الاستخدام ويُلغى عند تسجيل الخروج أو تغيير كلمة المرور.
- طلب استرجاع لا يكشف وجود اسم المستخدم. رابط الاسترجاع أحادي الاستخدام، محفوظ كتجزئة، وتنتهي صلاحيته بعد 20 دقيقة. يرسل إلى بريد الإدارة المهيأ في `admin_verification_email` (`algeriaset7@gmail.com`).
- عند تغيير كلمة المرور تلغى كل الأجهزة المتذكّرة؛ يظل TOTP مطلوباً في الدخول التالي، ثم رمز البريد.

## المرحلة 3 — معاينة واعتماد المالك

قبل الرفع نراجع معاً شاشة الدخول، شاشة الاسترجاع، ورسالة الإعداد المطلوبة للبريد. لا يجري إرسال بريد حقيقي في البيئة المحلية؛ يلزم ضبط `mail_from` لصندوق بريد نطاقك في cPanel وSPF/DKIM لاختبار التسليم.

## المرحلة 4 — GitHub وVercel

- يمكن إنشاء مستودع GitHub خاص لحفظ المصدر، ويمنع `.gitignore` رفع `config.php` وقاعدة SQLite والمفاتيح وبيانات العملاء.
- لا نربط Vercel كتطبيق إنتاج لهذه النسخة: لا يوفر خادماً دائماً لـPHP/SQLite ولا مكاناً آمناً لبيانات الطلبات أو مفاتيح OTP.
- إن لزم رابط معاينة على Vercel، يمكن نشر نسخة عرض ثابتة منفصلة فقط، بلا لوحة إدارة أو استرجاع كلمة مرور أو حفظ طلبات.

## المرحلة 5 — النشر الإنتاجي على cPanel

1. إنشاء صندوق بريد نطاق مثل `noreply@your-domain.com` وضبطه في `config.php` ضمن `mail_from`.
2. تفعيل SPF وDKIM، ثم اختبار رابط الاسترجاع إلى `algeriaset7@gmail.com`.
3. رفع ZIP إلى `public_html`، تفعيل امتدادات PHP المطلوبة، إنشاء المدير، حذف `create-admin.php`.
4. اختبار الدخول وTOTP ورمز البريد و«تذكّر هذا الجهاز» والاسترجاع وطلب متجر تجريبي.

لا نبدأ أي رفع خارجي قبل موافقة المالك على مرحلة المعاينة وامتلاك وصول GitHub/cPanel.
